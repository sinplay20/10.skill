# MCP 写入与核验

本流程用于活动 Logseq OG 图谱的实际写入。离线结构预览、skill 打包和规范讨论不执行图谱变更。

## 写前定位

1. 检查当前可用 Logseq MCP 工具及参数；用 search 返回信息确认 `mode: "markdown"` 和目标图谱。DB 模式不套用本 skill。
2. 查询页面名、别名、作者和可核实标识，读取候选页面。对象唯一匹配时复用；不得只因标题相近合并不同作品、讲座或会话。不要切换图谱。
3. 读取受影响的完整子树、属性、父级及同级顺序。数学与来源校验基于用户选定原始材料；已有摘要不代替完整原文。
4. 内部建立目标树和修改清单，记录实际 UUID 与来源定位。先创建缺少的被引对象并取得 UUID，再写跨块引用。内部计划不额外写成图谱 TODO。

最小内部记录通常只需：目标页面／根 UUID、修改前内容、预期父块与顺序、引用目标、实际新 UUID、读回结果。不是图谱必须采用的 JSON schema 或数据库。

## 工具行为与增量写入

- 用 `get_page_content`、`get_block` 读取；按当前 schema 解析返回值。连接器可能把 JSON 放在 MCP text 内容中，不能把显示用字符串误当完整结构。
- 已有块用 `update_block` 按 UUID 修改；新块用 `insert_nested_block` 或适当的页面 append。一个多行公式、表格、代码围栏或约定的多行索引记录保留为一个原子块。
- `insert_nested_block` 的 parent UUID 与 sibling 参数含义以当前 schema 为准；parent 表示参照块时，sibling 插入的位置不是该参照块的子树。写后读取实际 parent／left 关系。
- 新建需要被引用的公式块时，使用连接器支持的方式在创建时保存其新身份，并读回确认 UUID 稳定后再写引用。例如 OG 的 `insert_nested_block.properties.id` 可保存新块身份；不得把既有块的 id 复制到新对象。若保存后标识变化，按实际内容及父子顺序重新定位，不能继续使用失效 UUID。
- 同一父块下的插入串行执行。独立只读检查可并行，不用并发插入赌同级顺序。
- 连接器支持的 create-page 去重行为不能代替查重和读回。整页 Markdown 解析也不能代替精确的数学结果块边界。
- 小范围修正不使用整页 replace；不删除无关内容，不重建整棵已有结果以获得新排版。不直接编辑活动图谱文件、不操作其数据库、不绕过 MCP 调原始 HTTP。
- OG 不使用 DB 专属 `set_block_properties`。普通块属性可在受支持的块内容更新中维护，保留未涉及属性。

## Paper／Book 头部与类型索引

遵守 paper.md 的共同规则及 book.md 的书籍范围和 Chapter 层级规则：

- 默认首块仅为对应的 `#Paper` 或 `#Book`，不建立 alias pre-block，不通过 `create_page.properties` 或 `update_page.properties` 写入书目字段。书目信息从原始索引记录或 Zotero 核实；不默认另抄重复字段块。Index 按 Preprint version / Published version 分组，各版本下放 Zotero 一行入口和对应索引记录；当前正文采用的唯一分组标题附 (Current version)；#Comment on Version 是 Index 的直接子块，与版本组同级。
- 迁移时先确认原始索引记录或 Zotero 已能准确定位文献，再清除冗余书目块、涉及的原生属性和 alias；可先清空旧 alias 值，核对原生关系解除，再移除不再需要的前置块。保留 canonical page、类型根、原文结果及所有引用目标。
- 不因为旧标题实体存在就调用 delete_page；先核对 alias、内容和入链。无引用实体可能随解析自动消失，不能据此声称做过主动页面删除或界面图谱核验。
- 只有用户明确请求页面 alias 时才创建并验证原生关系。此时当前连接器的 `update_page.properties` 可能写到第一个既有块；普通块上的 alias 字典或标题实体不足以证明关系成功。索引状态未出现时，核对已保存内容后做一次有针对性的读取，不通过反复新建页面修复。
- 保存被引块身份可能增加原生 `id::`；保留必要身份信息，不复制旧块的 `id::` 到新块。取消书目属性不等于清除数学结果的 UUID。
- `{{query [[Paper]]}}` 或 `{{query [[Book]]}}` 查询对应的 inline 类型标记。默认普通书目文本不再支持 `(property year ...)` 等过滤；不要自动恢复属性。query 工具仅支持简单 DSL 时不传 raw Datalog；pathRefs 返回的后代不等于新的类型根。

## 重组与身份保留

优先使用当前连接器明确支持的 move／reparent 能力。未提供这类工具时，不假定更新内容能移动块。

- 有引用的数学结果、假设和记号根应保留 UUID。若无法安全移动，保留现有维护位置并在目标位置引用，或在能完整维护引用的既有授权范围内另定具体重组方式；不静默复制成两个维护位置。
- 仅对可安全迁移的访问元数据或评论采用新建、核对、再删除旧块。先检查可取得的入链与受影响范围；搜索覆盖不足时不能据此断言完全无入链。必要时保留旧入口作简短转向，避免制造失效引用。
- 新建块的 UUID 必然不同。记录旧／新映射与实际保留的根，迁移评论保留原始署名，不笼统声称全部 UUID 未变。
- 删除前读回新子树，检查文本、来源链接、顺序与引用；不能把目标文字出现视为旧引用已修复。

## 失败、重试与范围收束

超时、截断或结果不确定时，先读取目标页面／父块确认操作是否已生效。以实际内容及身份决定跳过、补齐或修正，不能盲目重复 insert。

出现无法定位的来源、冲突版本或工具不支持的操作时，停止依赖该条件的变更，继续完成独立且已授权部分；回报具体缺项。不得换用直接文件写入绕过连接器限制，也不扩大为自动同步、插件安装或 Zotero 写入。

## 写后核验

按实际修改范围核验；一条标题修正不要求重跑整份文献导入。

| 对象 | 可观察证据 |
|---|---|
| 内容与层级 | 受影响完整子树的内容、原子边界、parent 与同级顺序；Paper 节／Book 章标题的 Markdown 层级与块层级一致（Book Chapter ###、Section ####，以下标题只加粗） |
| 数学结果 | 共享条件与各结论分开、局部条件保留、证明归属正确、真实来源编号不变；练习根使用 #Exercise，题目与原 UUID 保留 |
| 数学环境引用 | 后文的环境名称和编号指向正确结果根或明确的分项；重复编号按实际语义区分，原生 refs 已核验；结果与证明归属标题不变成自引用 |
| 编号公式 | 每个编号恰有一个只含完整公式与原编号的块；前后正文分开且归属正确；多行公式未拆散，后续编号引用的原生 refs 指向对应公式块 |
| UUID | 已有根和被引结论身份保留；实际迁移的新 UUID 有记录 |
| 引用 | 描述性块引用含真实目标，目标可读取，原生 refs 对应同一块／页面；不能只检查文本 UUID，也不把显示别名误当页面 alias |
| Paper／Book 头部 | 首块仅对应的 `#Paper`／`#Book`、默认无 alias／书目属性，Index 入口简洁且版本明确，原始索引格式保持，类型查询正常；明确使用 alias 时才核验其原生关系 |
| 来源入口 | Zotero、MathSciNet 等归入实际对应版本；来源内部格式不变，版本组为 Index 直接子块。普通编号结果无重复 PDF 链接；使用可选定位时，核对作品／附件 key 和实际页码映射 |
| 评论 | Paper／Book 版本评论为 Index 直接子块 #Comment on Version，其他编辑评论在 Full-text 外；Research 评论归属具体结果，署名可核实 |
| 范围 | 无意外 TODO、重复页、空占位章节或未授权导入；未涉及人工内容保留 |

最终回报区分：离线计划、真实 MCP 写入、结构读回、来源 PDF 视觉核对、Logseq 界面渲染、数学核验与操作系统点击跳转。构造并核对 Zotero URI 不代表已观察到打开阅读器。
