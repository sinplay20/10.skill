## Lecture note 页（试用）

### 用途与对象身份

承载一次讲座的课件内容与明确要求补入的听讲笔记。一场讲座对应一个页面，同一讲座的课件修订或后续听讲补录复用该页；同名但讲者、日期或场次不同的讲座不自动合并。

- 以真实课件、可核实的讲者、讲座日期及活动语境识别来源；不能仅凭标题或同名文件判定同一场讲座。身份歧义影响复用或写入时，只询问缺少的区分信息。
- Lecture note 与相关 Paper、Topic 页面分别承载不同对象，不因内容重合而合并。可靠匹配时可引用已有页面，不自动建立全部被提及对象的页面。

### 页面名称

页面名称使用讲座的正式标题 `<Lecture title>`，不加 `Lecture note` 前缀。保留官方标题作为来源身份；需要生成的替代标题遵守 English-language policy。没有可核实标题时，先请用户提供名称。

重名且确认属于不同讲座时，以已核实的讲者、日期或场次补充最少的区分信息，例如 `<Lecture title>; <Speaker>; <YYYY-MM-DD>`。不为填充后缀猜造日期，也不占用已有的不同类型页面。

### 首个顶层元数据块

```text
- #Lecture-note
  speakers:: [[Speaker One]], [[Speaker Two]]
  date:: <YYYY-MM-DD>
  event:: [[Event or seminar series]]
  source:: <Actual source link or exact source filename>
```

| 属性 | 要求 |
|---|---|
| `speakers` | 已核实的讲者，按来源顺序使用页面引用；不把共同作者自动视为讲者。未知时省略。 |
| `date` | 已核实的讲座日期，完整日期用 `YYYY-MM-DD`；不能以下载、上传或文件修改日期代替。不能确定完整日期时省略。 |
| `event` | 可核实的活动或系列名称，使用页面引用；没有时省略。 |
| `source` | 必须记录本次实际使用的课件来源。优先保留可复查的附件引用或 URL；只有上传文件时保留准确文件名，并说明其可访问性限制。不是原始可复查路径的临时副本不能伪装为永久来源。 |

- 标签与上述属性属于同一个首块，按示例顺序排列可用字段；不增加 `tags::`、Paper 的原生 alias 前置块或未核实属性。示例占位值不写入实际页面。
- 记录实际使用版本的来源；新版课件与既有来源不一致时，先核对对应内容，不静默替换来源或将不同版本的文字拼作一份原文。
- 与其他页面类型一致，使用块引用查询 `{{query [[Lecture-note]]}}` 查找类型首块；需要日期筛选时，在同一块上使用 `(property date <YYYY-MM-DD>)` 条件。

### 正文结构

元数据块之后，每个课件帧标题直接作为一个普通顶层块，内容放在其子树中，保留用户指定的“标题 → 内容”结构。不额外包入 `Slides` 或 `Full-text` 层，也不自动生成 Paper 的 Summary、Index information 等章节。

```text
- #Lecture-note
  speakers:: [[Speaker]]
  source:: <Actual source link or exact source filename>
- <First frame title>
  source-pages:: 1-2
  - <First source paragraph or list item>
    - <Source subitem>
  - <Another source item>
- <Second frame title>
  source-pages:: 3
  - #Definition <Original number and name, when present>
    - <Source definition>
```

- `<Frame title>` 使用真实帧标题文字，不强制增加 Markdown 标题符号或重新编号；副标题有意义时一并保留。无标题帧使用可追溯的生成标题 `Untitled slide <source page number>`，不猜造主题。
- `source-pages` 是帧块的属性，记录实际来源文件中从 1 起算的物理页／幻灯片位置，如 `3`、`3-5`；不将 Beamer 显示的帧号误当 PDF 物理页码。每个已导入帧保留映射，便于核对和补录。
- 按来源顺序排列，保留各段落、列表项与子列表的从属关系。完整表格、代码围栏和多行公式作为原子内容，不按内部换行拆散。
- 明确属于同一 Beamer 帧的逐步显示页面可合并为一个完整帧块，`source-pages` 覆盖所有对应物理页，保留每一步新增、替换或撤回的有意义内容。不能只取最后一页而丢失早先出现后消失的陈述。替换或撤回改变含义时，以带来源页码的有序子块保留演化，不将互不兼容的版本拼作同一有效陈述；不能可靠合并时保留分开。
- 仅凭相同标题不合并帧；两个独立同名帧仍是同级块。无法确定是否为逐步显示时保留分开，并说明不确定性。
- 封面、目录、参考文献与附录若在用户选定范围内，按其实际帧位置保留；不另建一套脱离课件顺序的参考文献章节。

### 内容与语言边界

- 默认忠实转录选定课件中的可见内容，保留措辞、陈述条件、结论、编号、引文与顺序；不是默认摘要。只有用户要求时才生成精简笔记，并明确与原文转录的区别。不套用 Paper 的三种完成度。
- 笔记正文遵守 English-language policy；非英文正文完整翻译后，在受影响帧内标明 `English translation of the source text`，保留可复核来源。译文不称为逐字原文。
- 数学环境使用 [tags.md](tags.md) 的准确标签，但仅在来源明确为相应环境时添加。环境块仍属于对应帧；不以 `#Theorem` 等标签替代帧标题，也不为普通幻灯片内容猜造定理类型、编号或证明。
- 行内公式用 `$...$`；完整行间公式的起止 `$$` 各占独立物理行，多行环境、编号与反斜杠保持完整。编号公式必须单独成块，后文编号引用指向真实公式块；无编号独立公式通常单独成块，公式仍保留对其陈述的从属关系；排版与读回检查沿用 [paper.md 中的 Full-text 公式约定](paper.md#full-text-功能单元内的内容格式)，只读取相应公式规则，不扩大课件导入范围。
- 图示、交换图与图像型公式结合视觉来源核对，保留图注及必要的对应关系。能通过受支持方式保留原图时放在对应帧下；否则明确标记遗漏或不确定处，不用猜测性描述充当原图，也不宣称图示已完整归档。
- 口头讲解、听讲问题和个人批注仅依据用户提供或明确要求的内容补入。附在对应帧或内容块下，使用 `#Comment` 及其子块署名规则，区分讲者原话、用户笔记和生成的解释；不能将生成解释伪装为讲者陈述。
- 不默认读取隐藏幻灯片或演讲者备注，不凭课件补造未取得的口头内容。范围有限、来源缺页或内容不可辨认时，在对应位置标明并在回报中说明。

### 增补与核验

- 写前读取候选页面，核对类型首块、讲座身份及实际来源；复用同页时以来源位置及内容核对已有帧，不仅靠标题去重。
- 同一课件重复导入不重复添加帧。同一讲座的修订课件可能改变页码，须结合内容重新核对映射；不能按旧页码直接覆盖。更新已有帧时精确修改受影响块，保留 UUID、人工批注和未涉及的内容。
- 以用户选定范围为核验边界，逐帧核对顺序、`source-pages`、覆盖情况及逐步显示的合并；读回首块与全部受影响子树，检查公式和原子内容边界。可访问界面时核验渲染；静态读回不等于视觉验证。
- 回报实际页面名、课件来源、已导入范围及仍有的遗漏或不确定处。不把技能规范更新、离线预览或部分转录称为完成真实图谱写入。
