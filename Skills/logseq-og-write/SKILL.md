# Logseq OG 数学写入

基于 logseq-knowledge-base 与 Morrey／Garofalo–Rotz 实际试写整理的独立写入 skill，初版整理于 2026-11-08。全部运行规则随本包提供，无需再读取旧 skill 或某个历史工作目录。旧 skill 保留，未被替换。

## 请求与范围

- 先区分预览、图谱写入、规范修改。设计或更新 skill 不授予图谱写入权限；用户已明确要求写入且目标、范围、来源清楚时，继续执行，不重复确认。
- 完整收录 Paper 使用用户选定的 Bibliographic、Research-ready、Full-text；明确指定某个定义、命题或章节时按节选范围执行，不强迫扩大到一个完成度等级。修正既有页面不要求重新选择等级。
- Book 已正式支持，首块仅 `#Book`；Index、数学环境、公式和引用等沿用 Paper。正文按用户选定章／节／整本导入，Chapter 使用 `###`，Section 使用 `####`，#### 以下的标题只加粗并保留真实块嵌套。范围清楚时直接执行，不再以“书籍规范待定”要求重新确认。
- Research 组织当前论证；Paper 保存来源论文；Book 保存书籍；Topic 承载可复用概念。讲座与会话按实际来源身份和选定范围处理。一次架构测试采用足以验证结构的真实小范围。
- 缺失信息只有在影响身份、范围或正确性时才需要询问。来源不足时完成可核实部分，说明缺项，不补造原文、编号、UUID 或完成度。

## 写作与知识单元

- 笔记行文使用英文；真实作品标题、文件名、路径、标识和来源字面值保留。非英文正文按共同规则完整翻译并标明，不能把译文称为逐字原文。
- 页面对应稳定对象，块子树对应可引用的定义、假设、结果、计算或证明。不要为每个结论建页，也不要为可引用性增加新标签或属性。
- 一个结果根保留环境、真实编号与名称；共享条件、各项结论作为直接子块，证明归属该结果。使用某一结论时引用具体结论块，条件仍须完整给出或精确引用。
- 设定按可独立使用的对象细分：群运算、向量场、水平梯度、算子、测度、伸缩、维数、规范和球等。保留已有汇总根 UUID。
- `#Problem`、`#Conjecture`、`#Assumption` 各表其数学含义；未核验的证明草稿不自动变成猜想。假设保存条件，稿件标签和出处集中记录，不逐条重复长 Source。
- 树层级表示内容归属，不能当作假设继承。证明依赖、工具应用、相关文献分别用行文和真实块引用说明；研究加工不能冒充来源原文。
- 每个编号公式独立成块，后文编号引用指向公式块本身；保留原编号与数学归属，详见共同规则中的“编号公式与引用”。
- 行文中采用 `[descriptive text](((真实 UUID)))`。文献优先引用已有规范 Paper 或 Book 页；后文引用已收录的定理、引理、命题、定义等数学环境时必须指向相应结果块，具体分项按实际目标引用。练习根使用 `#Exercise`；详见共同规则与标签约定。
- Codex 会话入口使用 `[真实完整会话标题](codex://threads/真实线程ID)`；这不等于归档正文，也不充当 ChatGPT conversation-id。
- 默认不添加 TODO、DOING、LATER 或待办清单。研究进展和证明缺口用真实数学问题或必要评论表达。

## Paper、Book 与 Zotero 的关键约定

- 默认不创建页面 alias；首块只放对应的 `#Paper` 或 `#Book`。书目信息复用原始索引记录或链接的 Zotero 条目，不另抄重复字段块，不默认创建书目属性或作者／期刊页面链接。需要保存的文字保持普通文本，描述性块链接继续保留。
- Index information 的直接子块依次为 Preprint version、Published version、#Comment on Version；按实际已导入来源保留版本分组。Zotero item 一行入口和 MathSciNet 等索引记录归入对应版本；版本评论与两个版本分组同级。入口不附 PDF／DOI 子树；原始索引格式保留，不补造缺失来源。普通编号定义／结果默认不逐条加 PDF 链接，图表、无编号或难定位段落及明确的一键跳转需求按需保留。
- 版本分组标题整体加粗，包括括号中的标记。当前正文采用的版本分组标题附 `(Current version)`，同一 Paper／Book 页仅标一组；以实际采用版本为准，不自动等同最新版本，不新增标签或属性。
- MathSciNet、arXiv 按真实来源和约定格式保存；不把 Zotero 的 MR 字段或 PDF 首页拼成索引原文。来源缺失时省略，不建空标题。
- `## Full-text` 下 Paper 的节使用 `###` 并按原结构组织子节；Book 的 Chapter 用 `###`、Section 用 `####`，以下标题只加粗。实际块的父子关系始终保留。页面级编辑性 `#Comment` 位于 Full-text 之外；Research 的结果评论可留在该结果下。
- 普通 `#Comment` 父块只放标签；版本评论使用 `#Comment on Version`，不另建标签类型。每条评论子块末尾附可靠作者／模型署名，搬运保留原署名，新内容按实际生成者署名。
- 本版 Zotero 联动保持只读；显式访问链接和按需核对不等于自动双向同步。优先复用 Logseq 文献页，集中记录来源身份、附件和版本，不在行文中反复展开长 Source。

## 执行与交付

仅通过已配置 Logseq MCP 修改活动 OG 图谱。先确认 markdown 模式、匹配既有页面、读取受影响子树并建立目标结构，再小批量精确写入。保留 UUID、人工编辑和未涉及内容；同一父块的写入顺序执行。失败或超时先读回，不能盲目重试。

写后核验正文与数学边界、父子和同级顺序、块身份、原生引用索引，以及涉及的类型查询；只有明确使用页面 alias 时才核验其原生关系。结构读回、PDF 视觉核对、Logseq 界面渲染、数学证明核验和 Zotero 点击跳转分别报告，未执行的不能算通过。

交付简述实际页面和范围、关键结构变化、核验结果与缺项。局部修正保留未满足的完成度或原文范围说明，不为让报告显得完整而扩大导入。
